## Compaction

> 💡 **Best Practice:** Manual CompactionBecause automated context compression can erase specific file changes and debugging details, many developers prefer to disable it entirely. Instead, keep an eye on your context bar. Once you finish a micro-task, manually guide the compaction yourself by running:

```bash
/compact focus on active changes to the authentication router
```
